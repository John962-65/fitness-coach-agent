# fitness-coach-agent — 长期陪伴的私人健身教练 Agent

一个运用专业知识、持续理解个人、随用户变化调整并能修正判断的私人教练系统。
核心闭环：`专业知识 + 动态个人模型 → 可解释的教练决策 → 用户确认与执行 → 真实反馈 → 修正认识`。

当前状态：**核心工程闭环具备，进入受控试用阶段；尚未完成全部人工验收，不应视为成熟产品**（详见 `DESIGN.md` 第 23–25、27 章）。

最近的代码审查与修复见 [DESIGN_AUDIT_2026-10-22.md](DESIGN_AUDIT_2026-10-22.md)：离线回归 439 项通过；真实对话、专业内容与长期使用验收分别记录。

## 组成

- `coach/` — 运行时（安全前置规则、槽位式计划生成、打卡/复盘/调整闭环、记忆契约、目标协商、教练卡通道）
- `knowledge/` — 按教练场景组织的知识文件（分层加载：常驻原则 / 索引 / 按需全文）
- `exercises/` — 动作库（结构化属性 + 教学字段，含替换与伤病筛选）
- `claims/` — 观点条目池（可追溯 draft/审核状态；对外仅"转述 + 出处"）
- `eval/` — 评测集与 runner（断言工具调用与数据库状态，非回复文本）
- `tests/`（`test_*.py`）— 离线回归（临时库、模拟 LLM、禁真实数据与网络）
