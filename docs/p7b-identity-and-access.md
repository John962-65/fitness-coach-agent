# P7-B 身份、权限与账户生命周期

> 基线：`7d99993`｜ 日期：2026-10-27
> 状态：**本地模式权限硬化已交付（test_p7b.py 5 项 + 账户删除闭环）；
> 互联网多用户身份方案为设计文档（部署前硬要求，见 §3）**

## 1. 两种访问模式（必须区分）

| | 本机单用户模式（当前） | 互联网多用户模式（公开部署） |
|---|---|---|
| uid 来源 | 客户端声明（建档时自定） | 服务端会话/令牌绑定身份 |
| 网络边界 | 回环绑定默认；局域网必须设 `API_ACCESS_TOKEN` | HTTPS + 每用户身份 |
| 授权 | 服务端逐查询 `user_id=?` 过滤 | 同左 + 资源属主校验中间件 |
| 合规边界 | 个人本地工具 | 数据保护/隐私政策/安全日志必须齐备 |

**公开云服务不得直接复用单一共享令牌作为全部用户的身份方案。**

## 2. 本地模式硬化（已实施）

- 越权矩阵回归（`test_p7b.py`）：b 改 URL 只能得到自己的空数据——
  训练统计/事实/进阶候选（recent_sessions 空）/周期统计/洞察/任务/
  尝试/限制/症状；按 ID 触达（洞察查看/已读/忽略/重分析、尝试结束、
  提案确认、纠错）一律拒绝（404/422）；
- 导出严格本用户（`exported_for` 固定，无他人数据）；
- 令牌边界：配置 `API_ACCESS_TOKEN` 后无令牌/错令牌一律 401
  （`/api/health` 除外，供前端探测）；
- **账户删除**（数据自主最小闭环）：`DELETE /users/{uid}/account?
  confirm=DELETE` ——删除该用户在全部含 user_id 表中的数据并返回逐表
  计数；媒体文件由部署级清理回收。

## 3. 互联网多用户身份方案（设计；公开部署前实施）

1. **身份**：注册/登录（邮箱或 OAuth），argon2/bcrypt 口令散列；
   会话 = 签名 JWT（短效）+ 服务端可撤销 refresh 令牌表
   （`token_id, user_id, expires_at, revoked_at`）。
2. **授权**：中间件把 `uid` 从令牌解析并**覆盖**路径参数 uid——
   路径 uid ≠ 令牌 uid 一律 404（不泄露存在性）；管理员操作独立角色表。
3. **媒体**：`/api/media/*` 签名 URL 绑定 user_id + 过期时间；
   上传走服务端代理而非直写。
4. **频率限制**：按 user_id + IP 双维度滑动窗口（登录/导出/LLM 路由
   严格阈值）。
5. **安全日志**：登录成功/失败、令牌撤销、导出、账户删除写入
   append-only 审计表。
6. **数据保留**：账户删除 = 全表删除 + 媒体回收 + 审计留痕（不含健康
   数据）；备份导出前必须二次确认。
7. **验收门**：本文件 §2 的越权矩阵在多用户模式下全部复跑并通过，
   加上并发会话/撤销/限流测试——未通过不得公开部署。
