## 二、训练模板系统（场景 A ✓）

- 数据：`training_templates` 表（用户隔离）；`db` CRUD；路由
  `GET/POST/DELETE /users/{uid}/training-templates`（名称必填、entries 非空校验）。
- **对象边界**（复查要求）：模板可复用；修改模板不影响现有计划与已保存训练；
  会话永远保存执行快照。UI 文案与实现均明确这一边界。
- 入口：自由/模板训练中「存为训练模板」（记录动作、顺序、记录类型、超级组分组）；
  训练页「训练模板」卡：列表 / 开始（`/workout/template/:id`，预填动作与分组）/
  删除 / 导出 JSON / 导入 JSON。
- 恢复语义：同模板会话重复进入 → `resumed` 原样继续；不同会话冲突 → 用户选择。

## 三、多记录类型（场景 B ✓）

- `SetRecord` 判别联合：`weight_reps`（默认，兼容旧记录）/ `bodyweight_reps`
  （次数 + 可选额外负重）/ `assisted_reps`（次数 + 必填辅助重量）/ `duration`
  （秒）/ `distance_time`（米 + 秒，农夫行走可带负重）。
- 动作库声明 `measurement` 字段（首批：引体向上/反手/悬垂举腿/负重引体 =
  bodyweight_reps；平板支撑 = duration；农夫行走 = distance_time；其余默认
  weight_reps）；列表接口透出该字段。
- 训练界面按类型渲染对应输入控件与校验（`validateSetDraft`：次数整数 1-100、
  负重 0-500、RPE 1-10、时长/距离范围）。
- **分析分型，绝不混用公式**（复查强调）：
  - weight_reps：容量=负重×次数；e1RM（1-12 次区间）；
  - bodyweight_reps：容量只计**额外负重**×次数（自重不可比不计入）；核心指标是最多次数；
  - assisted_reps / duration / distance_time：不计 kg 容量、不参与 e1RM；
  - 聚合派生同步分型（bodyweight_reps 的负荷=额外负重）；
  - PR 新增「最长单组」「最远距离」；「我的表现」按类型显示可用指标。

## 四、超级组（场景 C ✓）

- 会话/模板条目携带 `superset_group`（A/B/C，明确分组而非备注文字）；
  自由训练卡片区一键分组；历史与详情显示分组标签；保存/模板/统计全链路透传。
- 交替执行：每个动作独立逐组记录（互不覆盖）；组间休息计时照常（可跳过）。
