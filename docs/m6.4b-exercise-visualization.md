## 三、B2/B3：三维动作演示引擎

### 制作方式（重要偏离说明）

**Blender 在本环境不可用**（无法产出 .blend 工程文件）。等价方案：
`tools/exercise3d/` 程序化生成包 —— 该包即「可编辑工程源文件」（改动
骨骼/动画 = 改 rig.py / motions/*.py 后重导出）：

```
tools/exercise3d/
├── rig.py          # 26 骨骼真实层级（Mixamo 风格命名）+ FK + 2 连杆 IK
├── meshgen.py      # 蒙皮人体网格（关节融合顶点权重，真实 skinning）
├── equipment.py    # 杠铃/哑铃/平凳/立式靠背凳/地面
├── gltfbuild.py    # 手写 GLB 序列化（skin/动画通道/材质）
├── motions/        # 五个动作的运动学脚本（公共求解器 common.py）
├── build.py        # python3 -m tools.exercise3d.build <id...>
└── manifest.py     # manifest 生成/更新（sha256、阶段表、预览图）
```

- 空间规范：Y-up、米制、角色面朝 +Z、地面 y=0、杠铃沿 X；人台身高 1.78m。
- **动画是真实骨骼驱动**：关键帧覆盖髋/膝/踝(足)/躯干/肩肘手 + 器械平移，
  局部旋转由「目标世界姿态」烘焙；顶点带蒙皮权重（关节区 50/50 融合带），
  绝非整体平移冒充。
- **人-械同步由构造保证**：器械握点由同一套运动学解算（杠位=双肩中点+胸廓
  系偏移；卧推/硬拉/划船/肩推的器械路径锚定 FK 实测肩位），生成期自检
  脚踝漂移/握点间隙 < 1e-15（`motions.*.build()['checks']`）。
- 深蹲杠轨迹钉在脚中正上方（z=0.05±1e-15，两遍解算）。

### 播放器（`frontend/src/components/exercise3d/`）

Exercise3DViewer / AnimatedModel / PlaybackControls / CameraPresets /
ModelFallback。React 18 + three 0.169 + @react-three/fiber 8.17 +
@react-three/drei 9.114（锁定版本）。能力：播放/暂停、循环、0.25/0.5/1/2×
倍速、拖动进度（作用于 AnimationAction 真实时间）、正/侧/背预设 + 重置、
单指旋转/双指缩放（OrbitControls）、教学阶段提示（标注「教学说明，不构成
个人动作判定」）、「示例动画·未人工复核」角标。
加载策略：`React.lazy` 按需加载（three 在独立 chunk，主包不变）；
dpr≤1.75；暂停时 frameloop=demand；卸载 `useGLTF.clear` 释放资源；
WebGL 探测 + contextlost + ErrorBoundary 三重降级，均不白屏。

## 四、B4：与训练系统集成

- 三维只按稳定 exercise_id 关联（`demo_3d` 拒绝非内置 ID）；**自定义动作
  即使 pattern 相同也不透出公共三维**（回归测试覆盖）。
- 训练中「教学」入口沿用既有路由；**修复一处 B4.2 违规**：未提交的逐组
  输入原为组件本地状态，进教学页返回会清空——现镜像到 store
  （`session.drafts`，`setEntryDraft`），实测教学往返 + 整页刷新输入均保留；
  会话/休息计时/模板身份本就在 store，不受影响。
- 阶段提示随动画进度高亮（如「下蹲（离心）」），并标注为教学说明；
  不生成任何个人动作判定。

    → 拖动到 1.9s（底部姿态正确渲染）→ 拖拽旋转 → 正/侧/背/重置 → 循环一致；
  - WebGL 上下文丢失模拟 → 降级文案 + 图文回退按钮，不白屏；
  - 布局：390×844 / 430×932 / 768×1024 / 1440×900 均正常；

    站立/拖动视角）。
- **人工动作审核（B5.3）**：五个动作逐项检查比例/骨骼驱动/器械同步/脚部

## 六、已知限制与未完成（如实）

1. **Blender 工程源文件缺失**：环境无 Blender；.blend 交付物未产出，
   以生成脚本包等价替代（本文开头说明）。
2. **公共视频演示为 0**：无已确认授权素材；视频入口仅用户自导可见。
3. **真机手机验证未做**：无真实手机设备，移动端以 390/430 视口实测代替；
   录屏证据以关键帧截图替代。横竖屏切换、真机内存曲线待有设备后补。
4. **教学内容全部为 draft**：AI 依据仓库知识库整理，未经人工复核；
   65/70 动作无结构化教学（覆盖报告如实反映）。
5. 动画关节角度为常见教学比例（深蹲杠过脚中、卧推触胸位等），非个体化
   诊断；模型为人台风格低多边形，非解剖精确。
6. 阶段提示依赖 manifest 时间区间，与动画时长硬编码一致（3.6s）；
   若改动作时长需同步 manifest（manifest.py 会自动重算）。
7. 预览图为浏览器关键帧截图（非独立渲染管线），与 GLB 同版本入库。
