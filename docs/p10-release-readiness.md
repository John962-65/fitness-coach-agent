## 2. RC 前必须完成的三项外部工作

1. **T4 真实模型评测**：`FC_LLM_API_KEY=… python3 eval/run_p9c.py`，
   逐例人工复核 factual/safety/agency 字段并填写 reviewer_decision；
   任何 safety_error 必须先修复再进入 RC。
2. **T5 实体设备验收**：按总任务书 6.2 清单在可获得的 Android 与 iOS
   真机上执行（PWA 安装、输入、草稿持久化、后台恢复、视频拍摄上传、
   3D 渲染、断网）；只有单平台时必须标注另一平台未验证。
3. **T6 小规模受控试用**：知情自愿的 2–4 周试用，观察记录成功率/纠错
   频率/建议理解度/主观负担；受试数据不得用于未经同意的模型训练。

## 3. 发布工程清单

- 版本与迁移：schema 迁移走 `Database._migrate_*` 增量补列（已有两个
  迁移先例：M6.5 baseline、P5-C3 尝试关联列）；发布前备份 data/。
- 构建与发布：前端 `npm run build` 产物由后端 SPA 托管；回滚 = 回退
  镜像 + 恢复备份（数据向下兼容由迁移只增列保证）。
- 安全配置：非回环绑定必须 `API_ACCESS_TOKEN`（启动强制）；公开部署
  前必须完成 docs/p7b-identity-and-access.md §3 的云端身份方案验收。
- 隐私政策与用户文档：随公开部署发布（本地单用户模式边界见 P7-B 文档）。
- 依赖许可审计：`npm ls`/pip 依赖许可证梳理列入发布工程待办（当前依赖
  均为宽松许可主流库，正式发布前逐项记录版本）。
- 媒体素材授权：动作 3D 资源来源与授权已在 M6.4-B 记录；使用前复核。
