# inbox/ — 知识原料收集区

> 这里是知识库的"前院"：博主新内容、用户暴露的缺口素材，先进 inbox，经过提炼和人工审核后才能进 knowledge/。
> **inbox 里的内容不会被 Agent 直接加载。**

## 工作流（设计书 8.1）

```
博主发布新内容
    ↓
① 收集：文字稿/笔记丢进本目录
   - 命名规范：YYYYMMDD_博主_主题.txt
   - 视频转文字工具：飞书妙记 / 通义听悟 / B站字幕（BBDown）
    ↓
② 提炼：手工（当前）或 tools/distill.py（Phase 2）
    ↓
③ 审核：发起人对照原意把关（不可省略）
    ↓
④ 入库：
   - 新主题 → knowledge/ 建新文件
   - 补充 → 追加到现有文件，刷新 updated 字段
   - 推翻 → 修改并标注"替代旧观点"
    ↓
⑤ 记录：knowledge/CHANGELOG.md 记一行
    ↓
⑥ 归档：处理完的原料移入 inbox/processed/
```
