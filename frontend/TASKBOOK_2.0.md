## 十一、M3.1 统一知识库与文档导入（2026-10-24，发起人"继续"）

对照 2.0 §六/§十三 M3 任务 1–4、8–9；视频线（任务 5–7、10–13）如实留待 M3.2。

| 项 | 实现 |
|---|---|
| 统一检索服务（任务1–3） | `coach/knowledge_search.py`：一个入口四个引擎——knowledge_md（provenance 来自 front-matter，按命中关键词数排序）、blogger_claims（approved 给内容+出处；draft 只报数量不展示，沿用审核纪律）、coach_cards（运行时可用才命中）、user_imports（仅 approved）；关键词为 CJK 二元 shingle；**pending/quarantined 永不进结果** |
| 知识对象（§6.4） | 新表 knowledge_sources / knowledge_chunks / knowledge_claims：内容哈希去重（同内容拒重复导入）、来源/出处字段、审核状态、风险隔离标记、疑似重复/冲突证据（JSON 留档） |
| 文档导入（任务4） | `POST /knowledge/imports`：text/markdown/文章粘贴 + **PDF（pymupdf 提取）**；三状态分离如实呈现：资料已保存 ≠ 提取通过 ≠ 审核通过 |
| 观点提取（任务8） | `coach/knowledge_import.py` 规则草稿提取（句子主张信号 + 领域粗分类），**确定性、零 LLM**——全部 pending_review，以用户逐条审核为准 |
| 重复/冲突检测（任务9） | 与博主 approved 观点 + 本人已审观点比对：CJK shingle 预筛 + difflib 相似度——≥0.72 疑似重复、0.5–0.72 且归类不同疑似冲突，证据进待审卡（前端标注） |
| 高风险红线（M3 验收） | 风险词（类固醇/利尿剂/极端断食等）**优先于信号过滤**直接 quarantined；审核端点拒绝放行（422）；隔离内容永不进检索/处方依据 |
| 前端 | 探索页双 tab：动作库｜知识库（统一检索四引擎卡片 + 导入表单 + 待审核列表[通过/拒绝/重复冲突标注] + 隔离区[红显、不可放行说明]） |

**验证**：test_m3.py 12 项（检索引擎/审核门/哈希去重/风险优先/重复冲突/分词鲁棒/PDF）；全量回归 **551 passed**（539 零退化）；E2E：检索四引擎（draft 303 条只计数）→ 导入（3 待审+1 隔离）→ 通过"蛋白质"条 → 统一检索"我的导入"命中。

**边界（M3.2 对象）**：视频上传/音频转写（faster-whisper）/关键片段识别/动作候选提取与确认/封面生成未做；规则提取是草稿级（明确标注非模型提炼），真实 LLM 提炼需额度授权；向量检索未做（§10.3 允许）；教练卡引擎在私有卡库缺失环境自动跳过。
