# 减脂平台期突破

## 先判断：是真平台还是假平台？

**以下情况不是平台期，先自查：**

| 假平台 | 真相 |
|--------|------|
| 只称了 2-3 次体重 | 日常波动（水分/钠摄入/排便）可达 1-2kg，看**周平均值** |
| 称重时间不固定 | 必须固定：晨起、空腹、排便后 |
| 刚开始减脂 1-2 周 | 时间太短，给身体 3-4 周 |
| 饮食记录有遗漏 | 酱料、饮料、零食是隐形热量大户 |
| 女性生理周期 | 经前一周水分潴留，体重假性上涨 |

**真平台标准**：饮食训练执行到位的前提下，**周平均体重连续 2-3 周无变化**。

## 真平台的机制（陈石瘦素体系）

```
长期热量缺口 → 瘦素显著下降 → 代谢降低 + 食欲飙升
→ 身体进入"节能模式" → 体重停滞
```

这不是你不够努力，是**生理学**。

## 突破方案（按优先级，循证优先）

### 方案 1：先排查热量误差 / 重新核算 TDEE（最常见）

- 减脂 4-8 周后体重下降，TDEE 也随之下降——原来的"缺口"可能已经变成"维持"
- 先**重新计算 TDEE**、核对饮食记录有没有漏记（酱料/饮料/零食）
- 多数"平台"其实是执行误差或 TDEE 漂移，先把这一步排掉再谈别的

### 方案 2：Refeed（高碳日）

- **每周 1 天**将碳水提高到维持热量水平（蛋白质不变，脂肪降低）
- 作用：回升瘦素、补充肌糖原、心理缓解
- 注意：是**计划内的高碳日**，不是放纵餐

### 方案 3：Diet Break（饮食休息期）

- 平台超过 3 周 → **回到维持热量 1-2 周**
- 听起来"反直觉"，但陈石体系核心：**先修复代谢，再谈继续减**
- 休息期保持训练，体重可能回升 1-2kg（主要是水分和糖原），不要慌

### 方案 4：训练端调整（周期化思路）

- 安排一个**卸载周**（重量降到平时约 50%、RPE 5-6、组数可减半），降低皮质醇
- 之后切换训练刺激（改变次数范围/动作变式）
- **不要**在平台期疯狂加有氧——只会加速代谢适应

## 绝对禁止

- ❌ 进一步砍热量到 1200 大卡以下
- ❌ 每天疯狂有氧
- ❌ 断碳/极端饮食

> 陈石："水体重掉得越快，代谢掉得也越快。"

## 给 Agent 的话术参考

> "你这周平均体重和上周持平，但饮食执行率 90%——这是典型的代谢适应信号，不是你不努力。按陈石的方法，我建议这周安排一天高碳日：碳水加倍、蛋白质不变。另外记录一下睡眠——你最近睡得怎么样？皮质醇高也会压住体重。"
