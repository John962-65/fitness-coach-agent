# 渐进超负荷（Progressive Overload）

> **三家共识：没有渐进超负荷，就没有进步。**

## 什么是渐进超负荷

身体适应当前刺激后，必须**逐步增加负荷**才能继续进步。负荷不只是重量，还包括：

| 负荷类型 | 具体方式 | 适用场景 |
|---------|---------|---------|
| **重量** | 增加杠铃/哑铃重量 | 最直接的方式 |
| **次数** | 同样重量做更多次 | 新手期、力量耐力 |
| **组数** | 增加总组数 | 容量提升 |
| **密度** | 同样时间做更多功 | 减脂期、时间有限 |
| **难度** | 更难的动作变式 | 徒手训练、进阶 |
| **质量** | 更标准的动作、更慢的速度 | 技术精进期 |

## 凯圣王的周期化应用

凯圣王将渐进超负荷融入**4 周周期**：

```
第 1-2 周：力量期（8-16 次/组）
  → 每周尝试加重 2.5-5kg
  → 高次数到低次数，兼顾力量和耐力

第 3 周：容量期（12-25 次/组）
  → 不加重，但增加总容量（组数 × 次数）
  → 弥补耐力短板

第 4 周：卸载周（50% 强度）
  → 主动恢复，为下一周期蓄力
  → 不是停止，而是"舒服的完成训练"
```

**关键**：卸载后第 5 周应能突破第 1-2 周的重量。

## 陈石的强度观

陈石从**激素和恢复**角度补充：

- **高强度**（大重量低次数）：提升力量、神经募集，但皮质醇升高明显
- **高容量**（中等重量多次数）：增加总消耗、肌肥大，但恢复时间长

**平衡策略**：
- 增肌期：强度为主，容量为辅
- 减脂期：保持强度（保肌肉），适度容量（增加消耗）
- 高压/熬夜期：**降低强度**，优先恢复

## 谭成义的技术质量观

谭成义强调：**质量优于数量**。

- 同样重量，**动作标准度提升**也是渐进超负荷
- 同样重量，**控制速度更慢**（离心 3 秒）也是进步
- 同样重量，**感觉更精准**（目标肌肉主导）也是进步

**新手常见错误**：只追求重量数字，忽视动作质量，导致：
- 关节受伤
- 目标肌肉没刺激
- 平台期提前到来

## 实践 checklist

- [ ] 本周比上周**多做了一次**或**加重了一点**？
- [ ] 动作质量**没有下降**？
- [ ] 恢复**跟得上**（睡眠、饮食、压力管理）？
- [ ] 如果连续 2 周无进步 → 考虑**改变负荷类型**（不只是加重）

## 适用场景

- 所有训练者的长期进步
- 平台期突破
- 新手福利期最大化利用
