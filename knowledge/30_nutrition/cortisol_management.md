# 皮质醇：代谢的头号杀手

## 皮质醇过量的恶性循环

- 肌肉分解加速 → 脂肪异常堆积（尤其**腹部**）
- 血糖调节紊乱 → 胰岛素抵抗
- 免疫力低下、水肿明显
- 综合表现：**"又胖又肿、肌肉减少、代谢下降"**

陈石对压力型肥胖的解释（转述）：人体的应激机制跟不上现代生活节奏——心理压力会让血液中的甘油三酯转化为游离脂肪酸，但由于没有实际的体力消耗，这些脂肪酸代谢不掉，最终堆积在腹部，形成压力型肥胖。

## 皮质醇管理方案

| 该做的 ✅ | 不该做的 ❌ |
|----------|-----------|
| 压力大时**优先睡觉**，而非运动 | 戒咖啡因（升高皮质醇） |
| 瑜伽、散步等低强度恢复活动 | 高强度训练（让皮质醇更高） |
| 降低生活压力源 | 疲劳时强行运动 |
| 保证热量不低于基础代谢 | 女性长期低于 1200 大卡 |
| 高压力期暂停热量赤字 | 高压力期同时严格节食 |

## 关键认知

- 皮质醇是**保命激素**，不是敌人——过量才是问题
- 慢性压力 + 极端节食 = 代谢灾难
- 睡眠不足是皮质醇升高的主要诱因

## 适用场景

- 用户自述"压力大""熬夜""失眠"
- 腹部脂肪堆积明显（苹果型身材）
- 减脂期同时经历高压工作/生活事件
