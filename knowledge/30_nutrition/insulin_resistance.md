# 胰岛素抵抗

## 胰岛素的三大功能

1. **降血糖**（第一功能）
2. **蛋白质合成**——增肌核心激素之一
3. **脂肪合成**——胰岛素与睾酮、生长激素并称"增肌三大核心激素"

## 胰岛素抵抗的成因链

```
皮质醇过量 → 血糖持续偏高 → 胰岛β细胞超负荷分泌
→ 细胞对胰岛素敏感性下降 → 胰岛素抵抗
→ 脂肪囤积 + 代谢紊乱
```

## 修复路径

- 控制**精制碳水**摄入量和进食频率
- **力量训练**提高骨骼肌胰岛素敏感性
- **降低皮质醇**（压力管理 + 睡眠）
- **修复消化系统**——肠道菌群影响胰岛素敏感性
- 与**多囊卵巢综合征（PCOS）**高度相关——修复胰岛素抵抗是改善 PCOS 的关键

## 适用场景

- 用户有血糖异常、糖尿病前期
- 女性用户 PCOS 相关问题
- 长期高压力 + 高碳水饮食人群
