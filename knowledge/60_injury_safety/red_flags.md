# ⚠️ 安全红旗清单（最高优先级，确定性规则）

> **本文件是系统安全底线，也是拦截关键词的唯一来源。**
> `coach/safety.py` 从一/二/三档表格的「关键词」列解析生成拦截词表（以 、分隔），
> 改本文即改拦截行为，同步由 test_safety.py 守护。
> 硬拦截（一/二档）→ 固定话术，不调 LLM；否定/提问/病史语境与黄色档 → 注入安全提示，由 LLM 结合上下文回应。

## 一、急症红旗（立即停止训练 + 尽快就医；症状持续或加重拨打 120）

| 症状 | 关键词 | 话术要点 |
|------|--------|---------|
| 胸部症状 | 胸闷、胸痛、胸口疼、胸口痛、胸口闷、胸口压迫、胸口紧 | 胸部不适是必须重视的信号 |
| 呼吸症状 | 呼吸困难、喘不上气、喘不过气、气短、气促 | 呼吸困难不是正常训练反应 |
| 神经症状 | 眩晕、晕厥、晕倒、眼前发黑、天旋地转 | 眩晕晕厥可能涉及多种原因，训练必须先停 |
| 心脏症状 | 心悸、心慌、心跳漏拍 | 心悸必须停下评估 |
| 放射性疼痛 | 放射痛、放射到 | 疼痛放射模式需要专业评估 |
| 横纹肌溶解征兆 | 酱油色、可乐色、酱油色尿、可乐色尿、尿色变深、血尿 | 练后尿色变深是急症，切勿拖延 |

**统一话术框架**：立即停止训练 → 建议尽快就医 → 症状持续或加重请拨打 120 → 声明不做医疗诊断。

## 二、损伤红旗（立即停止当前动作，48 小时内冰敷，不缓解则就医）

| 症状 | 关键词 | 话术要点 |
|------|--------|---------|
| 尖锐疼痛 | 刺痛、剧痛、撕裂感、撕裂、突然剧痛 | 尖锐疼痛是组织损伤的信号 |
| 麻木 | 麻木、发麻、失去知觉 | 麻木提示神经可能受压 |

**统一话术框架**：立即停止引发症状的动作 → 不要带伤坚持 → 急性期冰敷 → 48 小时不缓解或加重请就医。

## 三、黄色预警（不硬拦截：降阶处理 + 观察，由 LLM 把建议融入回复）

| 症状 | 关键词 | 处理原则 |
|------|--------|---------|
| 训练中头晕 | 头晕 | 立即停下休息，补充水分和碳水，当日不再训练 |
| 关节隐痛 | 隐痛、关节疼、关节痛 | 避开引发疼痛的动作，观察一周，持续则就医 |
| 肌肉拉伤感 | 拉伤 | 停止该动作，RICE 原则（休息/冰敷/加压/抬高） |
| 恶心呕吐感 | 恶心、想吐、呕吐 | 停下休息补水，当日不再训练，注意强度管理 |
| 超长酸痛 | 酸痛 | 1-3 天是正常 DOMS；超过 5 天不缓解提示恢复不足，降量、优先睡眠 |

## 四、正常反应（教育用户，不属于红旗）

| 现象 | 解释 |
|------|------|
| 训练中肌肉灼烧感 | 乳酸堆积，正常 |
| 延迟性酸痛 1-3 天 | DOMS，正常适应 |
| 训练中气喘 | 心肺正常反应 |
| 力竭时轻微抖动 | 神经肌肉疲劳，正常 |

## 五、Agent 行为准则（写死）

1. **命中一/二档 → 固定流程**：停止建议 → 就医提示 → 不诊断、不开药、不猜测病因；急症档必须含 120 提示
2. **否定/提问/病史语境不硬拦截**：如"我没有胸闷""头晕是怎么回事""以前刺痛过"——注入安全提示继续对话，并记录待跟进
3. **记录**：一/二档命中（含软化）记录到档案 `pain_flags`（结构化：时间/原文/命中词/档位/状态），后续对话主动跟进，用户确认无恙后关闭
4. **绝不承诺**："没事的""继续练就对了"类话术**禁止出现**
5. **边界声明**："我不是医生，我的建议不能替代专业医疗诊断"
